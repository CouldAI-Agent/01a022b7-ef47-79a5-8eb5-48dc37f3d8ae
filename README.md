# Beatly

Beatly is a social music-streaming app inspired by the concept of lyrics-driven, mood-based music discovery. 

## Features
- **Home/Discover Feed**: Trending songs, mood-based playlists ("Chill", "Workout", "Sad", "Party"), and "Made for You" rows.
- **Music Player**: Sticky bottom bar and full-screen "Now Playing" mode with a pulsing album art animation.
- **Synced Lyrics & Sharing**: Scrollable synced lyrics. Long-press a lyric line to generate a stylized, shareable "Lyric Card".
- **Bottom Navigation**: Easily move between Home, Search, Library, and Profile.

## Tech Stack
Built completely in **Flutter** (Dart), adapting original frontend requests to a highly polished, responsive native-feeling framework. It functions identically across Web, Android, iOS, and Desktop.

## Run Locally
1. Ensure Flutter is installed.
2. `flutter pub get`
3. `flutter run -d chrome` (for web testing)
